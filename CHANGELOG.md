# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - Initial Archival Release

### Added
- AVL tree implementation for Player management
- AVL tree implementation for Game management
- Nested AVL tree for Games Played per player
- CRUD operations (Create, Read, Update, Delete) for both trees
- CSV file persistence (save and load)
- Tree traversal utilities (preorder, inorder)
- Layer-based tree visualization
- Path finding between nodes
- Player game history lookup

### Technical Details
- Implemented self-balancing AVL trees for O(log n) operations
- Supports CSV import/export for data persistence
- Memory-efficient node structure with height tracking

### Notes
- This is an archived academic project
- No further active development planned
